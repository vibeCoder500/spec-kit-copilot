# T019-T021: Secure Foundation

Date: 2026-09-13. Windows, PowerShell 7.6.6, Node 24.19.0, npm 11.17.0.
The [two-canvas host gate](early-two-canvas-gate.md) passed before this work.
Source is the uncommitted development checkout based on `96ed37d9134c63d6cb05236879a8e1dcea010e3f`.

The dependency-free reader validates relative Markdown paths and each ordinary
filesystem component, reads through a bounded handle with a one-byte overflow
sentinel, compares identity/metadata, hashes exact bytes, and strictly decodes
UTF-8. The SDD vendor helper is generated by byte-for-byte copy and was hash and
syntax checked. No canvas routes use the new helper yet.

On this Windows filesystem, a freshly written file's `ctimeNs` changed between
path stat and handle stat while inode, device, size, and `mtimeNs` stayed equal.
A focused owned-file reproduction confirmed this. The reader compares identity,
size, and modification time across path/handle boundaries, plus change time
between before/after stats on the same open handle. It does not claim a sandbox
against malicious same-user filesystem races.

The in-memory context store issues opaque context/artifact/cursor identifiers,
revalidates scope and current membership, bounds retained contexts/cursors, expires
them, and limits a cursor chain to 10,000 inspected entries with 200-item pages.
Non-artifact entries count toward the limit. No context identifier grants access
without its owning server's authorization.
